可在左侧展开数据库，查看表数据、筛选、编辑、删除、导入 SQL 或导出建表和数据脚本。

条件关系

Ctrl + Enter 执行。输入 表名.字段前缀 或 别名.字段前缀 时可点击下拉建议补全字段。

连接 MySQL

输入 MySQL 服务器 IP（或主机名）后，系统会读取可访问的数据库和表。

编辑记录

带主键的字段用于定位记录，不能在此修改；没有主键时使用原始行数据定位，完全重复的行可能同时受影响。

导入 SQL

将在当前数据库执行 SQL 文件；失败前已执行的语句不会自动回滚。
